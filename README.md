# Veda AI — AI Assignment Generator

AI-powered assignment generation platform built with:

- Next.js
- TypeScript
- TailwindCSS
- Express.js
- Groq AI
- PDF Parsing

## Features

- Upload study material PDF
- Generate MCQ / Short / Long questions
- AI-generated answer keys
- Difficulty tagging
- Professional exam layout
- Download assignment as PDF
- Assignment dashboard
- View previous assignments

---

## Tech Stack

### Frontend
- Next.js
- TailwindCSS
- Zustand

### Backend
- Node.js
- Express
- TypeScript

### AI
- Groq API
- Llama 3.3 70B

---

## Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run dev
```

---

## Environment Variables

Create `.env` inside backend:

```env
GROQ_API_KEY=your_key
```
